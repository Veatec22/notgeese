# GRIME PL

Wersja **0.2** obejmuje cały tekst gry: interfejs, przedmioty, bestiariusz,
dialogi, samouczki i dodatki, także Nową grę+. Łatka dla **GOG 1.3.5**.
Początek gry przeszedł test gracza; pełna wersja czeka na sprawdzenie podczas rozgrywki.

## Instalacja

1. Zamknij grę. Jeśli masz próbkę 0.1, przywróć oryginał jej instalatorem.
2. Wypakuj cały ZIP do folderu z `GRIME.exe`.
3. Uruchom `GRIME-PL-0.2.exe`; program sprawdzi oryginał i zrobi kopię zapasową.
4. Włącz grę i wybierz **Polski** w ustawieniach języka.

Aby usunąć spolszczenie, uruchom ponownie `GRIME-PL-0.2.exe` i przywróć oryginał,
a następnie wybierz dostępny język gry. Zachowaj kopię
`data.unity3d.przed-spolszczeniem` do czasu przywrócenia. Paczka zawiera tylko
łatkę różnicową, program nakładający i instrukcję; nie zawiera zasobów gry.
