# Void Bastards PL

## Instalacja

1. Zamknij grę. Jeśli masz starsze spolszczenie, usuń folder `BepInEx/plugins/NieGesiVoidBastards` — inaczej gra uruchomi starą wersję zamiast nowej.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `Void Bastards.exe`. W Steamie trafisz tam przez **Zarządzaj → Przeglądaj pliki lokalne**.
3. Uruchom grę. Pierwsze uruchomienie potrwa chwilę dłużej niż zwykle.
4. W menu głównym wybierz **Language**, a potem **Polski**.

Spolszczenie nie podmienia żadnego pliku gry, a wszystkie oryginalne języki zostają na swoim miejscu. Żeby je usunąć, skasuj z katalogu gry folder `BepInEx` oraz pliki `winhttp.dll`, `doorstop_config.ini`, `BepInEx-LICENSE.txt` i `READ-ME.txt`.
