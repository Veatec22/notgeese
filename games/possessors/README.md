# Possessor(s) PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość archiwum do katalogu Possessor(s), czyli tam, gdzie jest folder `Pose`. W GOG Galaxy trafisz tam przez **Zarządzaj instalacją → Pokaż folder**, w Steamie przez **Zarządzaj → Przeglądaj pliki lokalne**. Jeśli masz starsze spolszczenie, pozwól nadpisać pliki.
3. Uruchom grę normalnie.
4. Otwórz ustawienia, znajdź **Language** i wybierz **polski**.

Spolszczenie nie podmienia żadnego pliku gry, tylko dodaje nowy język. Żeby je usunąć, wybierz w grze English, zamknij grę i skasuj trzy pliki `Pose/Content/Paks/pakchunk99-notgeesePL_P` (`.pak`, `.utoc`, `.ucas`).
