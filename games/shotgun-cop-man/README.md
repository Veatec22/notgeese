# Shotgun Cop Man PL

## Instalacja

1. Zamknij grę. Jeśli masz starsze spolszczenie, usuń folder `BepInEx/plugins/NieGesiShotgunCopMan` — inaczej gra uruchomi starą wersję zamiast nowej.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `Shotgun Cop Man.exe`. W Steamie trafisz tam przez **Zarządzaj → Przeglądaj pliki lokalne**.
3. Uruchom grę. Pierwsze uruchomienie potrwa chwilę dłużej niż zwykle.
4. Wejdź w **Options → Language**, wybierz **Polski** i zatwierdź przez **Apply Settings**.

Spolszczenie nie podmienia żadnego pliku gry, a wszystkie oryginalne języki zostają na swoim miejscu. Żeby je usunąć, skasuj z katalogu gry folder `BepInEx` oraz pliki `winhttp.dll`, `doorstop_config.ini` i `.doorstop_version`.
