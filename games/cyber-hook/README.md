# Cyber Hook PL

## Instalacja

1. Zamknij grę. Jeśli masz starsze spolszczenie, usuń folder `BepInEx/plugins/NieGesiCyberHook` — inaczej gra uruchomi starą wersję zamiast nowej.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `CyberHook.exe`. W GOG Galaxy trafisz tam przez **Zarządzaj instalacją → Pokaż folder**, a w Steamie przez **Zarządzaj → Przeglądaj pliki lokalne**.
3. Uruchom grę. Pierwsze uruchomienie potrwa chwilę dłużej niż zwykle.
4. Jeśli gra nie jest po polsku, wejdź w **Options → Gameplay → Language** i wybierz **English** — po zmianie ta pozycja nazywa się **Polski**.

Spolszczenie nie podmienia żadnego pliku gry, a pozostałe języki działają jak dotąd. Żeby je usunąć, skasuj z katalogu gry folder `BepInEx` oraz pliki `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `BepInEx-LICENSE.txt` i `READ-ME.txt`.
