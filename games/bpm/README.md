# BPM: Bullets Per Minute PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `BPMGame.exe`. W GOG Galaxy trafisz tam przez **Więcej → Zarządzaj instalacją → Pokaż folder**, a potem do `WindowsNoEditor`.
3. Uruchom `BPM-PL-0.1.exe`. Program sprawdzi pliki gry i utworzy w `BPM\Content\Paks` pliki `BPM-PL_P.pak` i `BPM-PL_P.sig`.
4. Uruchom grę i wejdź w **Settings → User Interface → Language**, wybierz **Polski** i zatwierdź przez **Save & Apply**.

Spolszczenie nie podmienia żadnego pliku gry, a wszystkie oryginalne języki zostają na swoim miejscu. Żeby je usunąć, uruchom `BPM-PL-0.1.exe` jeszcze raz i potwierdź przywrócenie albo skasuj z `BPM\Content\Paks` pliki `BPM-PL_P.pak` i `BPM-PL_P.sig`.
