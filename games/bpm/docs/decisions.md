# BPM: Bullets Per Minute: translation decisions

Facts and sources: `translations/bible.yaml`.

## Player and characters

- **No gendered forms toward the player.** Playable valkyries differ (GÖLL, SKULD female;
  FREYR, NJORD male per RU/FR tables). "killed by" = "zabójca:" (RU "убийца"), "UNLOCKED GÖLL" =
  "ODBLOKOWANO: GÖLL".
- **Valkyrie, boss and Norse proper names unchanged** (GÖLL, NIDHOGG, Hermóðr, Megingjord,
  Mjölnir, Svalinn…). Genitive declined in Polish: "Tarcza Lokiego", "Korona Ymira",
  "Błogosławieństwo Odyna", "Karwasz Sigrdrify".

## Opportunities taken

- Room grades FLAWLESS / GOOD / OKAY CLEAR = "BEZ SKAZY" / "DOBRA ROBOTA" / "MOŻE BYĆ".
- "Skjaldmeyjar's Plate" = "Pancerz tarczowniczki"; "Asp's Whisper" = "Szept żmii";
  "hexapod (look it up)" = "heksapod (sprawdź sobie)".
- "Seiðr's Hat / Blessing" = "Kapelusz / Błogosławieństwo seidu": seiðr is magic, not a person.

## Deliberate departures

- Original typos not carried over ("wheather", "Renerate", "Huggin's").
- "reverted back in {time} second" = "… za {time} s", no numeral declension.
- Developer/test entries (Label, Key1, Header, "Found culture…") stay English.
- Some item descriptions shortened for the narrow item box ("Obrażenia z czasem",
  "Szybkie przeładowanie", "Opóźnione wybuchy", "Autocelowanie").
