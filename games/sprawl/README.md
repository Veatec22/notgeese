# SPRAWL PL

## Instalacja

1. Zamknij grę.
2. Wypakuj archiwum do katalogu gry tak, żeby plik `Sprawl-WindowsNoEditor_pl_P.pak` trafił do `Sprawl/Content/Paks`, obok oryginalnego `Sprawl-WindowsNoEditor.pak`. W Steamie trafisz tam przez **Zarządzaj → Przeglądaj pliki lokalne**, w GOG Galaxy przez **Zarządzaj instalacją → Pokaż folder**.
3. Uruchom grę normalnie.
4. Strzałkami przy fladze wybierz biało-czerwoną flagę Polski.

Spolszczenie nie podmienia żadnego pliku gry, a wszystkie oryginalne języki zostają na swoim miejscu. Żeby je usunąć, skasuj przy zamkniętej grze plik `Sprawl-WindowsNoEditor_pl_P.pak`.
