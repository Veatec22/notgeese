# Anger Foot PL

## Instalacja

1. Zamknij grę. Jeśli masz starsze spolszczenie, usuń folder `BepInEx/plugins/NieGesiAngerFoot` — inaczej gra uruchomi starą wersję zamiast nowej.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `Anger Foot.exe`. W Steamie trafisz tam przez **Zarządzaj → Przeglądaj pliki lokalne**, w GOG Galaxy przez **Zarządzaj instalacją → Pokaż folder**.
3. Uruchom grę. Pierwsze uruchomienie potrwa chwilę dłużej niż zwykle.
4. Na ekranie tytułowym klikaj trzeci przycisk od góry — przycisk języka — aż pokaże **POLSKI**.

Spolszczenie nie podmienia żadnego pliku gry, a wszystkie oryginalne języki zostają na swoim miejscu. Żeby je usunąć, skasuj z katalogu gry folder `BepInEx` oraz pliki `winhttp.dll`, `doorstop_config.ini` i `.doorstop_version`.
