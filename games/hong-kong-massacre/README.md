# The Hong Kong Massacre PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `THKM.exe`. W Steamie trafisz tam przez **Zarządzaj → Przeglądaj pliki lokalne**, w GOG Galaxy przez **Zarządzaj instalacją → Pokaż folder**.
3. Uruchom grę. Pierwsze uruchomienie potrwa chwilę dłużej niż zwykle. Gra od razu jest po polsku.

Spolszczenie nie podmienia żadnego pliku gry. Żeby je usunąć, skasuj z katalogu gry folder `BepInEx` oraz pliki `winhttp.dll`, `doorstop_config.ini` i `.doorstop_version`.
