# Xolonium 4.3

Unmodified TTF files and documents from the official archive by Severin Meyer.
Source: https://sev.dev/fonts/xolonium/
Archive: https://gitlab.com/-/project/276995/uploads/90eb464d831cca476384030ba400673c/xolonium-fonts-4.3.zip
Downloaded 2026-09-25. License SIL OFL 1.1: `LICENSE.txt`.

`tools/font_assets.py` makes our own glyph strips from these TTFs. It never reads or copies
the Heat Signature publisher's atlases. Italic is synthetic. The license ships in the
package as `notgeese/LICENSE-XOLONIUM.txt`.
