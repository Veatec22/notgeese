# Heat Signature PL

## Instalacja

1. Zamknij grę. Jeśli masz starsze spolszczenie, możesz usunąć z katalogu gry folder `NieGesi` — nowa wersja już go nie używa. Pobierz paczkę Heat Signature PL 0.1. To wersja testowa pełnego spolszczenia: menu, samouczek, przedmioty, misje, podpowiedzi i wszystkie rozmowy. Nazwy frakcji i imiona zostają w oryginale.
2. W Steam wybierz **Heat Signature → Zarządzaj → Przeglądaj pliki lokalne**.
3. Wypakuj zawartość ZIP obok `Heat_Signature.exe`, tak aby znalazły się tam `d3d9.dll` i folder `notgeese`. Jeżeli masz już `d3d9.dll` od innego moda, zachowaj jego kopię i wyłącz tamten mod.
4. Uruchom grę ze Steama. Spolszczenie działa automatycznie. Teksty, których nie udało się przetłumaczyć, zostają po angielsku i trafiają do `notgeese/LogOutput.log`.

Aby usunąć spolszczenie, przy zamkniętej grze usuń dodany `d3d9.dll` i folder `notgeese`; jeśli wcześniej odłożono plik innego moda, przywróć jego kopię. Oryginalne EXE, dialogi i zapisy gry pozostają niezmienione.
