# El Paso, Elsewhere PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość paczki do katalogu z `El Paso Elsewhere.exe`. W Steamie trafisz tam przez **Zarządzaj → Przeglądaj pliki lokalne**.
3. Uruchom grę zwykłym skrótem. Pierwszy start potrwa dłużej (nawet kilka minut) i wymaga internetu — loader przygotowuje swoje biblioteki.
4. Gra od razu jest po polsku, nie trzeba niczego wybierać. Dubbing zostaje angielski, więc włącz napisy.

Spolszczenie nie podmienia żadnego pliku gry i nie zapisuje się w ustawieniach. Żeby je usunąć, zamknij grę i usuń folder `BepInEx/plugins/notgeeseElPasoElsewhere` — gra wróci do angielskiego. Jeśli był to jedyny mod, możesz też usunąć dodany loader: foldery `BepInEx` i `dotnet` oraz pliki `winhttp.dll`, `doorstop_config.ini` i `.doorstop_version`.
