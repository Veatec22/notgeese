# Rain World PL

## Instalacja

1. Zamknij grę. Jeśli masz starsze spolszczenie, usuń folder `RainWorld_Data\StreamingAssets\mods\niegesi-polski` — inaczej gra uruchomi starą wersję zamiast nowej.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `RainWorld.exe`. W GOG Galaxy trafisz tam przez **Zarządzaj instalacją → Pokaż folder**, a w Steamie przez **Zarządzaj → Przeglądaj pliki lokalne**. Mod trafi do `RainWorld_Data\StreamingAssets\mods\notgeese-polski`.
3. Uruchom grę i w menu głównym wybierz **REMIX**.
4. Zaznacz na liście modów **Polski (Not Geese)** i kliknij **APPLY**. Jeśli gra poprosi o ponowne uruchomienie, uruchom ją jeszcze raz.
5. Wejdź w **OPTIONS** i w sekcji **LANGUAGE** wybierz **POLISH** (po przełączeniu przycisk nazywa się już **POLSKI**).

Spolszczenie to zwykły mod Remix i nie podmienia żadnego pliku gry. Żeby je usunąć, przełącz najpierw język na inny (**OPCJE → JĘZYK → ANGIELSKI**), odznacz mod w menu **REMIX**, kliknij **APPLY** i skasuj katalog `RainWorld_Data\StreamingAssets\mods\notgeese-polski`.
