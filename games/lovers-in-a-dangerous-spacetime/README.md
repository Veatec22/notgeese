# Lovers in a Dangerous Spacetime PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `LoversInADangerousSpacetime.exe`. W GOG Galaxy trafisz tam przez **Zarządzaj instalacją → Pokaż folder**, w Steamie przez **Zarządzaj → Przeglądaj pliki lokalne**.
3. Uruchom grę. Pierwsze uruchomienie potrwa chwilę dłużej niż zwykle.
4. Wejdź w **Help & Options → Language**, strzałkami wybierz **Polski** i zatwierdź przez **Apply**. Jeśli system masz ustawiony na polski, gra przy pierwszym uruchomieniu sama wybierze polski.

Spolszczenie nie podmienia żadnego pliku gry, a wszystkie oryginalne języki zostają na swoim miejscu. Żeby je usunąć, skasuj z katalogu gry folder `BepInEx` oraz pliki `winhttp.dll`, `doorstop_config.ini` i `.doorstop_version`. Gra wróci wtedy do angielskiego.
