# NOT A HERO PL

## Instalacja

1. Zamknij grę. Wypakuj paczkę do katalogu zawierającego `NOT A HERO.exe`.
2. Uruchom `Not-A-Hero-PL-0.1.exe`. Aplikator sprawdzi pliki i zachowa oryginały.
3. Uruchom grę i wybierz **polską flagę** — zajmuje miejsce angielskiej.
   Jeśli w menu nie ma dźwięku, ustaw głośność w **OPCJE → DŹWIĘK**
   (to błąd samej gry przy pierwszym uruchomieniu).

Aby przywrócić oryginał, zamknij grę, uruchom ponownie `Not-A-Hero-PL-0.1.exe`
i wybierz przywrócenie. Zachowaj pliki `.przed-spolszczeniem` do tego czasu.
