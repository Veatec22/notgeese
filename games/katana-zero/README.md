# Katana ZERO PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `Katana ZERO.exe`. W GOG Galaxy trafisz tam przez **Zarządzaj instalacją → Pokaż folder**.
3. Uruchom `Katana-ZERO-PL-0.1.exe` dwuklikiem. Program sprawdzi wersję gry, odłoży oryginalne `Katana ZERO.exe` i `data.win` z dopiskiem `.przed-spolszczeniem` i nałoży łatki. Jeśli Windows ostrzeże przed nieznanym programem, wybierz **Więcej informacji → Uruchom mimo to**.
4. Uruchom grę i w wyborze języka (**Language**) wybierz **Polski**, na miejscu dawnego rosyjskiego.

Polski zajmuje w grze miejsce rosyjskiego, pozostałe języki zostają bez zmian. Żeby przywrócić oryginał, uruchom `Katana-ZERO-PL-0.1.exe` jeszcze raz i potwierdź przywrócenie albo zweryfikuj pliki gry w GOG Galaxy.
