# Hyper Light Drifter PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `HyperLightDrifter.exe`. W GOG Galaxy trafisz tam przez **Zarządzaj instalacją → Pokaż folder**.
3. Uruchom `Hyper-Light-Drifter-PL-0.1.exe` dwuklikiem. Program sprawdzi wersję gry, odłoży oryginalne `HyperLightDrifter.exe`, `MenuText.txt` i `Phrases.txt` z dopiskiem `.przed-spolszczeniem` i nałoży łatki. Jeśli Windows ostrzeże przed nieznanym programem, wybierz **Więcej informacji → Uruchom mimo to**.
4. Uruchom grę, wejdź w **Settings → Language** i wybierz **POLSKI**, na miejscu dawnego włoskiego.

Polski zajmuje w grze miejsce włoskiego, pozostałe języki zostają bez zmian. Żeby przywrócić oryginał, uruchom `Hyper-Light-Drifter-PL-0.1.exe` jeszcze raz i potwierdź przywrócenie albo zweryfikuj pliki gry w GOG Galaxy.
