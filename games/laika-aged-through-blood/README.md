# Laika: Aged Through Blood PL

## Instalacja

1. Zamknij grę. Jeśli masz starsze spolszczenie, usuń folder `BepInEx/plugins/NieGesiLaika` — inaczej gra uruchomi starą wersję zamiast nowej.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `Laika Aged through Blood.exe`. W GOG Galaxy trafisz tam przez **Zarządzaj instalacją → Pokaż folder**, a w Steamie przez **Zarządzaj → Przeglądaj pliki lokalne**.
3. Uruchom grę. Pierwsze uruchomienie potrwa chwilę dłużej niż zwykle.
4. Wejdź w **Settings → Game → Language** i wybierz **POLSKI**, ostatnią pozycję na liście. Gra zapamięta wybór.

Spolszczenie nie podmienia żadnego pliku gry, a polski pojawia się obok pozostałych języków. Żeby je usunąć, najpierw przełącz w grze język na angielski, a potem skasuj z katalogu gry folder `BepInEx` oraz pliki `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `BepInEx-LICENSE.txt` i `READ-ME.txt`.
