# DEADBOLT PL

## Instalacja

1. Zamknij grę. Jeśli masz starsze spolszczenie, możesz usunąć z katalogu gry folder `NieGesi` — nowa wersja już go nie używa.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `deadbolt_game.exe`. W Steamie trafisz tam przez **Zarządzaj → Przeglądaj pliki lokalne**.
3. Uruchom grę normalnie. Spolszczenie włącza się samo.

Spolszczenie nie podmienia żadnego pliku gry — poprawia teksty i fonty w pamięci przy starcie. Żeby je usunąć, skasuj z katalogu gry plik `d3d9.dll` i folder `notgeese`.
