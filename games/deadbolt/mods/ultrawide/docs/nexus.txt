[size=5][b]Ultrawide[/b][/size]

DEADBOLT renders a 960x540 view and adds black bars on wider screens. This mod widens the game's own view so 21:9 and 32:9 screens are filled, with the menus still working.

[size=4][b]Features[/b][/size]
[list]
[*]Wider view in missions, the dock and the apartment (32:9: 1920x540 instead of 960x540).
[*]Main menu and load screen centred, mouse hit areas moved to match.
[*]Width follows your main display automatically, or set it by hand.
[*]No game files are changed: the plugin adjusts the game's data in memory at start and checks every change against what it expects first.
[/list]

[size=4][b]Installation[/b][/size]
[list=1]
[*]Close the game.
[*]Steam: DEADBOLT > Manage > Browse local files.
[*]Extract the ZIP next to [b]deadbolt_game.exe[/b]: d3d9.dll and the ultrawide folder.
[*]Start the game normally.
[/list]

[size=4][b]Settings[/b][/size]
[i]ultrawide\settings.ini[/i] (restart the game after a change):
[list]
[*][b]Enabled=0[/b] turns the widescreen off.
[*][b]VirtualWidth=0[/b] matches your main display. A number (even, 961-3840) forces a width at 540 px height, e.g. 1280 for 21:9 or 1920 for 32:9.
[/list]

[size=4][b]Compatibility[/b][/size]
Tested at 32:9 (5120x1440) on Steam build 22449372. 21:9 is computed the same way but has not been tested in game yet; reports welcome. 16:9 and narrower screens are left unchanged.
The mod finds what it patches by the game's data structure and code patterns, not by fixed addresses or game version. If an update changes them, the widescreen switches itself off with a line in [i]ultrawide\LogOutput.log[/i] and the game runs normally.
The same d3d9.dll also runs the Not Geese Polish translation; both can be installed together. Other mods that ship their own d3d9.dll cannot run alongside this one.

[size=4][b]Uninstall[/b][/size]
With the game closed, delete [i]d3d9.dll[/i] and the [i]ultrawide[/i] folder.
