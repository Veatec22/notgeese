# Children of the Sun PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość archiwum do katalogu gry, czyli tam, gdzie leży `ChildrenOfTheSun.exe`. W Steamie trafisz tam przez **Zarządzaj → Przeglądaj pliki lokalne**.
3. Uruchom grę. Pierwsze uruchomienie potrwa chwilę dłużej niż zwykle.
4. Wejdź w **Options → Language** i wybierz **Polski**, ostatnią pozycję na liście. Gra zapamięta wybór.

Spolszczenie nie podmienia żadnego pliku gry, a polski pojawia się obok pozostałych języków. Żeby je usunąć, skasuj z katalogu gry folder `BepInEx` oraz pliki `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `BepInEx-LICENSE.txt` i `READ-ME.txt`; gra wróci do angielskiego.
